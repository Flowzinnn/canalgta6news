# GTA NEWS — link na bio

Página de links do canal [@canalgta6news](https://www.tiktok.com/@canalgta6news) no TikTok, com contagem regressiva para o GTA 6 e links de afiliado.

## Como editar os links
1. Abra o arquivo `index.html` aqui no GitHub e clique no lápis (Edit).
2. Procure o bloco `CONFIG`.
3. Cole cada link de afiliado entre as aspas de `link:""`.
4. Clique em **Commit changes**. O site atualiza sozinho em cerca de 1 minuto.

Botões com link vazio aparecem como "em breve".

Canal de fãs, sem vínculo com Rockstar Games ou Take-Two Interactive.
